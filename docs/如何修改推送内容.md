# 如何查看和修改推送内容

这份说明专门讲两件事：

- 现在企业微信机器人会推送什么内容
- 如果你想改推送文字、删掉某些字段、增加某些字段，应该改哪里

## 现在推送里有什么

当前触发提醒后，企业微信会收到一条 markdown 消息。

现在包含这些内容：

```text
## 定投提醒
- 标的: 代码 名称
- 备注: 你的备注
- 第几次触发: 第 N 次
- 当前价: 当前价格
- 昨收价: 昨天收盘价
- 当前涨跌幅: 相对昨收的涨跌幅
- 当前单日跌幅: 当前这一天相对昨收跌了多少
- 触发方式: 首次触发 / 相对上一次触发价继续下跌
- 起点价: 第一次计算时的起点
- 本次基准价: 本次触发用的基准价
- 相对起点累计跌幅: 从起点到现在累计跌了多少
- 下一次触发价: 下一次再提醒的价格
- 阶梯跌幅: 当前标的使用的跌幅阈值
- 时间: 检查时间

已达到你的定投提醒线，可以决定是否执行一笔。
```

其中：

- `备注` 只有你在配置里写了 `notes` 才会出现
- `第几次触发` 是这个标的第几次达到阶梯提醒
- `下一次触发价` 是下一档提醒线
- `阶梯跌幅` 默认是全局 `4%`，如果某个标的写了 `thresholdPct`，就用它自己的值

## 想删掉某一行怎么改

比如你不想推送 `昨收价`，找到这一行：

```js
`- 昨收价: ${alert.prevClose.toFixed(3)}`,
```

删掉这一行即可。

比如你不想推送 `当前涨跌幅`，删掉这一行：

```js
`- 当前涨跌幅: ${alert.rawChangePct.toFixed(2)}%`,
```

注意：每一行后面通常有英文逗号 `,`，删一整行最稳。

## 想改文字怎么改

比如你想把标题从：

```js
"## 定投提醒",
```

改成：

```js
"## 该定投了",
```

推送标题就会变成：

```text
该定投了
```

比如你想把：

```js
`- 当前价: ${alert.currentPrice.toFixed(3)}`,
```

改成：

```js
`- 现在价格: ${alert.currentPrice.toFixed(3)}`,
```

推送里就会显示：

```text
- 现在价格: 9.600
```

## 想增加一句固定提示怎么改

比如你想在最后加一句：

```text
记得确认仓位，不要冲动加太多。
```

就在最后这段附近：

```js
"已达到你的定投提醒线，可以决定是否执行一笔。"
```

改成：

```js
"已达到你的定投提醒线，可以决定是否执行一笔。",
"记得确认仓位，不要冲动加太多。"
```

注意：前一行末尾要加英文逗号 `,`。

## 想增加一个已有字段怎么改

脚本里当前能直接用的字段主要有这些：

```text
alert.symbol              代码
alert.name                名称
alert.notes               备注
alert.triggerCount        第几次触发
alert.currentPrice        当前价
alert.prevClose           昨收价
alert.rawChangePct        当前涨跌幅
alert.dropPct             当前单日跌幅
alert.triggerKind         触发方式
alert.basePrice           本次基准价
alert.initialBasePrice    起点价
alert.cumulativeDropPct   相对起点累计跌幅
alert.nextTriggerPrice    下一次触发价
alert.progressiveDropPct  阶梯跌幅
alert.checkedAt           检查时间
```

比如你想加一行显示“行情来源”，可以在 `lines.push(` 里面加：

```js
`- 行情来源: ${alert.source}`,
```

## 改完以后怎么检查

改完脚本后，在项目目录运行：

```bash
node --check scripts/github_actions_check.js
```

如果没有输出，就说明语法检查通过。

然后提交并推送：

```bash
git add .
git commit -m "update wecom message content"
git push
```

最后去 GitHub 手动跑一次：

1. 打开仓库
2. 点 `Actions`
3. 点 `DCA Alert`
4. 点 `Run workflow`

## 我建议你保留哪些字段

建议至少保留：

- 标的
- 当前价
- 第几次触发
- 相对起点累计跌幅
- 下一次触发价
- 时间

这几项最有用。

其他像 `昨收价`、`当前涨跌幅`、`触发方式`，可以按你的喜好删减。
