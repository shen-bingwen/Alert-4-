# 如何添加股票/基金代码

这份说明专门教你两件事：

- 往监控列表里添加一个新的股票或基金代码
- 设置它的跌幅提醒是多少

## 你现在主要改哪一个文件

主配置文件在这里：

- [watchlist.github.json](C:/Users/24951/Documents/Codex_66test/Dollar-Cost%20Averaging/config/watchlist.github.json)

加标的最方便的脚本在这里：

- [add_watch_symbol.js](C:/Users/24951/Documents/Codex_66test/Dollar-Cost%20Averaging/scripts/add_watch_symbol.js)

## 最简单的添加方法

先进入项目目录：

```bash
cd "/c/Users/24951/Documents/Codex_66test/Dollar-Cost Averaging"
```

然后直接添加一个代码：

```bash
node scripts/add_watch_symbol.js 512480
```

这条命令的意思是：

- `512480` 是你要监控的代码
- 脚本会尽量自动帮你识别名称
- 会自动把它加进监控列表
- 默认启用监控

如果你用的是 PowerShell，`npm run` 有时会被执行策略拦住，所以更推荐你直接用 `node`。

## 你想自己写名称

比如你不想让脚本自动识别，想自己写名字：

```bash
node scripts/add_watch_symbol.js 512480 "半导体ETF"
```

## 你想顺手设置跌幅和备注

比如你想加一个代码，同时规定它跌 `4%` 提醒，并写个备注：

```bash
node scripts/add_watch_symbol.js 512480 "半导体ETF" 4 "核心仓"
```

这里每一段的意思是：

- `512480`：代码
- `"半导体ETF"`：名称
- `4`：跌幅提醒百分比
- `"核心仓"`：备注

## 只想写代码和跌幅

你也可以不写名称，只写代码、跌幅、备注：

```bash
node scripts/add_watch_symbol.js 512480 4 "核心仓"
```

脚本会尽量自动查名字。

## 这个“跌幅多少”到底填在哪里

你有两种设置方式：

### 方式 1：全局统一跌幅

打开这个文件：

- [watchlist.github.json](C:/Users/24951/Documents/Codex_66test/Dollar-Cost%20Averaging/config/watchlist.github.json)

看这里：

```json
"rules": {
  "triggerDropPct": 4,
  "progressiveDropPct": 4
}
```

意思是：

- `triggerDropPct: 4`
  - 第一次触发时，跌 `4%` 提醒
- `progressiveDropPct: 4`
  - 以后每次都按“上一次提醒价再跌 `4%`”继续提醒

如果你想统一改成 `5%`，就改成：

```json
"rules": {
  "triggerDropPct": 5,
  "progressiveDropPct": 5
}
```

### 方式 2：单独给某个标的设置跌幅

比如你想让 `510300` 还是 `4%`，但某一个标的要改成 `6%`，那就在这个标的下面加：

```json
{
  "symbol": "512480",
  "name": "半导体ETF",
  "enabled": true,
  "thresholdPct": 6,
  "notes": "波动大，单独设成 6%"
}
```

这里的：

- `thresholdPct: 6`

意思是这个标的单独按 `6%` 执行。

现在这版脚本里，`thresholdPct` 会同时影响：

- 第一次触发跌幅
- 后续每次阶梯提醒跌幅

也就是说：

- 不写 `thresholdPct`：就用全局默认值
- 写了 `thresholdPct`：这个标的就按它自己的值来

## 一个完整示例

假设你现在想加：

- 代码：`159915`
- 名称：`创业板ETF`
- 提醒跌幅：`5%`
- 备注：`观察仓`

你可以直接运行：

```bash
node scripts/add_watch_symbol.js 159915 "创业板ETF" 5 "观察仓"
```

运行后，它会写进配置文件里，类似这样：

```json
{
  "symbol": "159915",
  "name": "创业板ETF",
  "enabled": true,
  "thresholdPct": 5,
  "notes": "观察仓"
}
```

## 如果你想手动改文件

也可以直接打开：

- [watchlist.github.json](C:/Users/24951/Documents/Codex_66test/Dollar-Cost%20Averaging/config/watchlist.github.json)

在 `watchlist` 里面照着现有格式加一项：

```json
{
  "symbol": "159915",
  "name": "创业板ETF",
  "enabled": true,
  "thresholdPct": 5,
  "notes": "观察仓"
}
```

注意：

- `symbol` 必须是 6 位代码
- `enabled: true` 才会监控
- 每一项后面的逗号要写对

## 添加完以后要做什么

如果你只是改了本地文件，还没有生效到 GitHub Actions。

你还要把改动 push 上去：

```bash
git add .
git commit -m "add watch symbols"
git push
```

然后去 GitHub 手动跑一次：

1. 打开仓库
2. 点 `Actions`
3. 点 `DCA Alert`
4. 点 `Run workflow`
